# Arcadecore Aesthetic Statement

## Selected aesthetic

I selected [Arcadecore](https://aesthetics.fandom.com/wiki/Arcadecore).

## Design choices

I used Arcadecore on my homepage but i still kept the normal website design as the default. I used a dark navy background with neon cyan magenta yellow and green colors because those colors remind me of arcade machines game screens and old arcade rooms.

The header is suppose to look like a arcade sign with the glowing border big letters and bright text shadow. The navigation links look like arcade buttons and they use different neon colors. The homepage sections look like arcade machine screens and the earthquake section looks like a live score feed. I also used CSS custom properties for the colors spacing borders and glow so the style stays consistent and is easier to understand.

## JavaScript enhancement

The homepage has a Enter Arcade Mode button that gets created with JavaScript. The script uses DOM methods and `addEventListener()` to add or remove `data-aesthetic="arcadecore"` from the html element. The choice gets saved in `localStorage` so Arcade Mode stays on after the page reloads. The normal light dark and system theme picker still works seperate from Arcade Mode.

## Usability and accessibility

The normal portfolio still works even if JavaScript is turned off because the Arcade Mode button only gets added when the script runs. Arcade Mode still has readable text strong contrast visible keyboard focus and links that are easy to see. On smaller screens the navigation wraps the controls fit on the screen and all the content stays in one column. The glowing animation also turns off when `prefers-reduced-motion` is enabled.

## The medium is the message

McLuhan saying the medium is the message means the way something is shown can change how people understand it. My website text says that im a computer science student but Arcade Mode shows more than just the words. It shows that i like experimenting being creative and mixing technical work with something more fun.

Since i control the HTML CSS and JavaScript the website itself becomes part of what im trying to say. The normal design shows the more clear and professional side of me while Arcade Mode shows a more creative and expressive side. The information is still the same but it feels different because the way it is presented changes the experience.
